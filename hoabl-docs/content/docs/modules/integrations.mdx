## Overview

This is an architecture view, not an ER diagram. It covers every external integration found in the HoABL production org &mdash; not just the three in the original component matrix &mdash; by cross-checking the Salesforce technical documentation against the org's live Remote Site Settings, Named Credentials, Connected Apps, Auth Providers, Call Centers and Email Services.

<Callout type="info" title="Reading the diagram">
  Salesforce is the hub; each integration is a spoke, grouped and colored by category. A solid arrow and solid node border means the integration is **confirmed**: a live Remote Site/Named Credential *and* a matching Apex class were both found. A dashed arrow/border means **config-only**: the connection is live in the org, but no Apex class could be tied to it by name &mdash; it may run through a Flow, a managed package, or be a newer feature not yet reflected elsewhere in the docs.
</Callout>

<Callout type="warn" title="What 'confirmed' does and doesn't mean">
  Classification is based on matching Apex class names already captured in this repo's component matrices, plus the live org metadata fetched for this page. It is not a full static-analysis pass over all ~3,300 Apex classes in the org, so a "config-only" entry may simply have a class this method didn't catch &mdash; it isn't necessarily unused.
</Callout>

## Messaging (SMS / WhatsApp / Email)

### Salesforce Marketing Cloud `config-only`

The Marketing Cloud Connect managed package (`et4ae5__`) is configured with 30+ Remote Site Settings covering REST, SOAP and auth endpoints across multiple Business Units and tenants. Flows prep SFMC-formatted fields (e.g. `Update_ChannelPartner_Mobile_SFMC_Format`) and the connector syncs them for email/SMS/WhatsApp journeys &mdash; this runs through the managed package and declarative flows rather than custom Apex, so no class names apply.

### WhatsApp Business API (Meta)

Sends WhatsApp template messages and receives inbound chat/media via the Meta Graph API.

| | |
| --- | --- |
| **Endpoint** | `graph.facebook.com`, `lookaside.fbsbx.com` (media) |
| **Objects** | `Case`, `Account`, `Booking__c` |
| **Config** | Remote Site: `Whatsapp_Media` &middot; Tab/LWC: `Whatsapp_Template_Dashboard` |
| **Classes** | `Ex_MetaAPIHandler`, `Ex_WhatsappChatServices`, `Ex_WhatsappMsgTriggerHandler`, `SendWhatsappMessage` |

### MSG91 &mdash; SMS / OTP gateway `config-only`

Live Remote Site Setting for `api.msg91.com`. No Apex class was matched to it by name &mdash; OTP sending may run through `Ex_TOTPGenerator`/`Ex_GoogleOAuthIntegrationWithOtp` or a Flow callout.

### Fab Media &mdash; SMS / WhatsApp gateway `config-only`

A second SMS/WhatsApp vendor, live as Remote Site `Fab_Media` (`sms.fabmediatech.com`). Purpose inferred from the domain only.

### Inbound Email Services
