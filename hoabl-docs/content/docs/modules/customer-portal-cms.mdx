## Overview

The CMS lets the team manage what customers see in the portal. Each tab of the admin screen maps to one group of objects, and every record hangs off a single **Portal Configuration** record. Images and documents are stored once as **File** records and referenced from everywhere else.

<Callout type="info" title="Reading the diagram">
  Colors match the CMS tabs: Login, Investment &amp; RERA, Latest Updates, Latest Offerings (with the home carousel) and
  Services. Grey tables are existing HoABL objects, included only so the relations have a target.
</Callout>

## Apex classes

| Class | Description |
| --- | --- |
| `CustomerPortal_CMSController` | Shared helper used by every CMS tab. Fetches the master Portal Configuration record, loads launch options for dropdowns, and creates or deletes File records for uploaded assets. Tab-specific logic lives in the dedicated controllers below. |
| `CustomerPortal_CMSLoginController` | Backs the **Login Carousel** tab. Creates, updates, deletes and fetches the login carousel images linked to the portal configuration. |
| `CustomerPortal_CMSLaunchController` | Backs the **Investment & RERA** tab. Manages the general launch info, investment carousel images and RERA details for each project and launch. |
| `CustomerPortal_CMSLatestUpdatesCtrl` | Backs the **Latest Updates** tab. Manages newsletters and videos together with their targeting rows. A content item is shown to a customer only when a targeting row matches the customer's Launch and Phase exactly. |
| `CustomerPortal_CMSOfferingsController` | Backs the **Latest Offerings** tab. Handles create, update, delete and fetch for the home page offerings, including validation rules and the customer tier picklist options. |
| `CustomerPortal_CMSServicesController` | Backs the **Services** tab. Manages each service along with its FAQs and process steps, including the card and content text and images shown in the portal. |
| `CustomerPortal_SiteContentProvider` | Single entry point the portal site calls for CMS content. It delegates to the login, home, launch, service, video, newsletter and alias providers, and its methods are cacheable. |
| `CustomerPortal_LoginContentProvider` | Returns the login page carousel images (up to 20) with image URL, alt text and serial number, in serial order. Only records that have an image are returned. |
| `CustomerPortal_HomeContentProvider` | Returns the latest offerings (up to 50) and the service FAQs shown on the portal home page, in serial order. Image URLs come from the linked File records. |
| `CustomerPortal_LaunchContentProvider` | Returns launch-specific content: the launch alias, the carousel images for the Investment Detail page, and the launch image used as the background on the Investment listing page. |
| `CustomerPortal_ServiceContentProvider` | Returns the portal services with their card and content text, images, FAQs and process steps, all ordered by serial number. |
| `CustomerPortal_NewsLetterContentProvider` | Returns the newsletters targeted to a given launch and phase, with publish date and preview and download URLs. Visibility is resolved through the newsletter targeting rows. |
| `CustomerPortal_VideoContentProvider` | Returns the videos (up to 50) targeted to a given launch and phase, with embed URL, thumbnail, channel details and publish date. Visibility is resolved through the video targeting rows. |
| `CustomerPortal_AliasContentProvider` | Supplies the display aliases for projects and launches, used in the portal in place of the Salesforce names, with a fallback value when no alias is set. |
| `CustomerPortal_FilePublicUrlHandler` | Called by the `CustomerPortal_FilePublicUrlTrigger` trigger when a file is attached to a File record. It picks the latest file version, creates a public distribution link, and stores the file name, size, download URL and preview URL on the File record. |
